# SparkAuto Vehicle Repair Tracking System
1. Save your logo as `public/images/logo.png` (a built-in logo.svg is used until you do).
2. `npm install` then `npm start`, open http://localhost:3000
3. First-run accounts (password `Spark@2026`): manager, admin, mechanic. Change or delete them in Users.
Forgotten password: the one-time reset code is printed in the terminal running the server.
Data is stored in `sparkauto.db` (SQLite). Set SESSION_SECRET in the environment for a stable session secret.
